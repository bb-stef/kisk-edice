# Pamětnice — web edice

Jednoduchá prezentační stránka začínajícího nakladatelství a edice *Pamětnice – ukrajinské autorky o paměti 20. století* (projekt ISKM03, KISK FF MU).

- `index.html` – obsah stránky
- `style.css` – vzhled (písmo Montserrat z Google Fonts)

Web běží na GitHub Pages z větve `main`. Každý push do `main` stránku automaticky aktualizuje.

## Co je potřeba doplnit

- název nakladatelství (`[Název nakladatelství]` v hlavičce a patičce)
- jména členů týmu v sekci „O nás“
